Portfolio Ecosystem Architecture

How the four modular services interoperate to power production-ready agents.

1. Axiom Runtime (:8001)

Flagship execution engine. Enforces legal status transitions, checkpoints state to SQLite/Postgres, and deduplicates tool executions with SHA-256 idempotency keys.

2. Memory Service (:8002)

Persistent memory graph. Extracts subject-predicate-object semantic facts, supersedes outdated knowledge, and ranks episodes by hybrid similarity, recency, and importance.

3. Evaluation Lab (:8003)

Objective evaluator. Runs 100 reproducible scenarios, grades trajectory fidelity, validates idempotency (0 duplicates), and tracks P50/P95 latencies.

4. Voice Capstone (:8004)

End-to-end voice agent. Listens to speech transcripts, queries memory for user context, executes tools via Axiom, and gates sensitive actions through supervisor approval.
